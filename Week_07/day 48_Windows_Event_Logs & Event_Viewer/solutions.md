# Day 48 – Solutions

## Task 1

### What are Windows Event Logs, and why are they important in cybersecurity?

Windows Event Logs are records automatically generated by the Windows operating system whenever an event occurs on a computer. These events include user logins, application errors, system changes, account creation, and many other activities.

They are important because they help security analysts monitor user activity, investigate security incidents, detect suspicious behavior, troubleshoot system problems, and support digital forensic investigations.

---

## Task 2

### Explain the purpose of Event Viewer.

Event Viewer is a built-in Windows tool used to access, view, search, and analyze Windows Event Logs.

It allows administrators and SOC analysts to:

- View system events
- Monitor security activities
- Filter logs
- Search specific Event IDs
- Export logs for investigations

---

## Task 3

### List and briefly describe the five main Windows Event Log categories.

**Application Logs**
Contain events generated by installed applications.

**Security Logs**
Contain authentication, authorization, and account management events.

**System Logs**
Contain events generated by the Windows operating system, drivers, and services.

**Setup Logs**
Record Windows installation and update events.

**Forwarded Events**
Contain logs forwarded from other computers to a central location.

## Task 4

### Explain the significance of the following Windows Security Event IDs.

**4624**
Successful user logon.

**4625**
Failed logon attempt.

**4672**
Administrator or privileged account logged in.

**4720**
A new user account was created.

**4728**
A user was added to a security-enabled group.

---

## Task 5

### Why are Security Logs the most valuable logs for a SOC Analyst?

Security Logs contain authentication events, account changes, privilege assignments, password changes, and other activities that can indicate malicious behavior.

These logs help analysts detect attacks such as brute-force attempts, privilege escalation, unauthorized account creation, and account compromise.

---

## Task 6

### Explain how Windows Event Logs help during a security investigation.

Windows Event Logs provide evidence of activities performed on a system.

By reviewing Event IDs, timestamps, user accounts, and system events, analysts can reconstruct what happened before, during, and after a security incident.

This information helps determine the cause of an incident, identify affected systems, and support incident response.
