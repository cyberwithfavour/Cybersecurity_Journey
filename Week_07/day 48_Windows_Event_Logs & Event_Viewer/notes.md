# Day 48 Notes – Windows Event Logs & Event Viewer

# What are Windows Event Logs?

Windows Event Logs are records automatically generated by the Windows Operating System whenever an event occurs on a computer.

These logs help administrators and SOC analysts monitor system activity, troubleshoot issues, and investigate security incidents.

Every login, application crash, account creation, or system error can generate an event log.

---

# Why are Windows Event Logs Important?

Windows Event Logs help security teams:

- Monitor user activity
- Detect suspicious behavior
- Investigate security incidents
- Troubleshoot system issues
- Meet compliance requirements
- Perform digital forensic investigations

Without logs, it would be difficult to understand what happened before, during, or after a security incident.

---

# Event Viewer

Event Viewer is a built-in Windows tool used to view and analyze Windows Event Logs.

It allows administrators and SOC analysts to:

- View system events
- Filter logs
- Search specific Event IDs
- Export logs for investigation

---

# Windows Event Log Categories

## Application Logs

Contains events generated by installed applications.

Example:
Microsoft Office crashes or application errors.

---

## Security Logs

Contains authentication and authorization events.

Examples:

- User logins
- Failed login attempts
- Account creation
- Password changes
- Privilege changes

This is the most important log for SOC analysts.

---

## System Logs

Contains events generated by Windows itself.

Examples:

- Driver failures
- Hardware issues
- Service startup/shutdown

---

## Setup Logs

Records Windows installation and update events.

---

## Forwarded Events

Contains logs forwarded from other devices to a central system.

---

# Important Windows Security Event IDs

## Event ID 4624

Successful Logon

Indicates a user successfully logged into the system.

---

## Event ID 4625

Failed Logon

Indicates a login attempt failed.

This Event ID is commonly used to detect:

- Brute-force attacks
- Password guessing
- Invalid credentials

---

## Event ID 4634

User Logoff

Indicates a user logged out.

---

## Event ID 4648

Logon Using Explicit Credentials

Occurs when a user logs in using different credentials.

---

## Event ID 4672

Special Privileges Assigned

Indicates an administrator account has logged in.

SOC analysts pay close attention to this event.

---

## Event ID 4720

User Account Created

Indicates a new user account has been created.

---

## Event ID 4726

User Account Deleted

Indicates a user account has been removed.

---

## Event ID 4728

User Added to Security Group

Indicates a user was added to a privileged group.

---

## Event ID 4732

Member Added to Local Group

Shows when a user is added to a local security group.

---

# Authentication Monitoring

SOC analysts monitor authentication events to identify:

- Successful logins
- Failed logins
- Account lockouts
- Administrator logins
- New account creation
- Privilege escalation

---

# Why Event IDs Matter

Rather than reading every log, analysts often search for specific Event IDs to quickly investigate suspicious activity.

For example:

4625 → Failed Login

4720 → New User Created

4672 → Administrator Privileges Assigned

---

# Key Takeaways

- Windows Event Logs record system activity.
- Event Viewer is used to access and analyze logs.
- Security Logs are the most valuable for SOC investigations.
- Event IDs help analysts investigate suspicious activities quickly.
- Windows Event Logs are one of the primary data sources for SIEM platforms.
