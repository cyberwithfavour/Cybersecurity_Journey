# Day 47 – Solutions

## Task 1

### Define a Security Information and Event Management (SIEM) system.

A Security Information and Event Management (SIEM) system is a cybersecurity solution that collects, stores, analyzes, and correlates logs from multiple devices, applications, and systems within an organization. It helps security teams detect suspicious activities, investigate incidents, and respond to threats efficiently.

---

## Task 2

### Explain three reasons why organizations use SIEM solutions.

1. **Centralized Log Management**  
   SIEM collects logs from multiple devices into one location, making monitoring and investigations easier.

2. **Threat Detection**  
   It analyzes and correlates events to detect suspicious activities that may indicate cyberattacks.

3. **Incident Response**  
   SIEM provides alerts and investigation tools that help SOC analysts respond quickly to potential security incidents.

---

## Task 3

### Describe the SIEM workflow from log collection to investigation.

The SIEM workflow consists of the following steps:

1. Log Collection
2. Log Aggregation
3. Log Normalization
4. Event Correlation
5. Alert Generation
6. Alert Investigation
7. Documentation and Response

This process enables SOC analysts to identify and investigate potential threats effectively.

---

## Task 4

### List at least five common log sources collected by a SIEM.

- Windows Event Logs
- Linux System Logs
- Firewalls
- Active Directory
- Antivirus / Endpoint Detection and Response (EDR)
- Intrusion Detection and Prevention Systems (IDS/IPS)
- Cloud Services (Microsoft Azure, AWS)

---

## Task 5

### Differentiate between SIEM and SOAR.

| SIEM | SOAR |
|------|------|
| Collects and analyzes security logs | Automates security response actions |
| Detects suspicious activities | Responds to incidents automatically |
| Generates alerts | Executes predefined playbooks |
| Assists analysts during investigations | Reduces manual work during incident response |

---

## Task 6

### Explain the difference between Log, Event, and Alert.

**Log**

A log is a recorded entry of an activity that occurs on a device, application, or network.

**Event**

An event is any observable action recorded in a log, such as a user login or file access.

**Alert**

An alert is a notification generated by the SIEM when one or more events match predefined rules indicating suspicious activity.
