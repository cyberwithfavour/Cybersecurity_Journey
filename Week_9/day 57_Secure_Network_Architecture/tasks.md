## Task 4

### Think Like a SOC Analyst

A company's network is designed as follows:

- Internet
- Firewall
- Internal Network

The company hosts:

- Public Website
- Email Server
- DNS Server
- Employee Workstations
- File Server

All of these systems are placed inside the **same internal network**.

Two months later, the public web server is compromised by an attacker.

Answer the following:

- Identify **five security design mistakes** in this architecture.
- Which systems are now at risk?
- How could the attacker move through the network?
- Which security principles discussed today were ignored?
- Redesign the architecture to make it more secure.
