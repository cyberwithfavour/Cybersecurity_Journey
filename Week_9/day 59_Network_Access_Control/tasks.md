- What security control failed?

- What compliance checks should have been performed before granting access?

## Practical Exercise

You are the security administrator for a company with the following users:

- Employees
- IT Administrators
- Contractors
- Guests
- Personal Devices (BYOD)

Design a basic NAC policy by answering:

- Which users should have full network access?
- Which users should have limited access?
- Which devices should undergo compliance checks?
- Which devices should only access the Internet?
- Under what conditions should a device be moved to a quarantine network?

Explain how your NAC policy reduces security risks while allowing legitimate users to work efficiently.
