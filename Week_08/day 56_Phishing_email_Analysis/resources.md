## Useful Tools

### Google Admin Toolbox

Analyzes email headers to identify:

- Sender information
- Routing path
- Authentication results

---

### MXToolbox

Used to investigate:

- Email headers
- DNS records
- Blacklisted domains
- Mail server configuration

---

### VirusTotal

Scans:

- URLs
- Files
- Domains
- IP Addresses

using dozens of antivirus engines.

---

### URLhaus

Used to identify URLs associated with:

- Malware delivery
- Phishing campaigns
- Command-and-Control infrastructure

---

### AbuseIPDB

Checks whether an IP address has been reported for malicious activity.

---

### AlienVault OTX

Provides threat intelligence including:

- Indicators of Compromise (IOCs)
- Threat reports
- Malware intelligence
- Domain reputation
