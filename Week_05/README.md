# 📖 Overview

This week focused on identifying, assessing, and mitigating security vulnerabilities while learning how organizations respond to cybersecurity incidents. I explored vulnerability management, system hardening, malware analysis, endpoint protection, and the phases of incident response.

These concepts are essential for reducing an organization's attack surface and ensuring effective detection, containment, and recovery from cyber threats.
