# 📖 Overview

This week focused on understanding how data is protected during storage and transmission through cryptography and how network security devices defend modern infrastructures against cyber threats.

I explored encryption techniques, hashing algorithms, digital certificates, Public Key Infrastructure (PKI), and the functions of common network security devices such as firewalls, IDS, and IPS.

These concepts are fundamental for protecting confidentiality, integrity, and availability within enterprise environments.

# 🎯 Learning Objectives

- Differentiate encryption from hashing

- Understand Public Key Infrastructure (PKI)
