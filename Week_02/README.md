# 📖 Overview

Week 2 focused on developing practical Linux and networking skills, which form the backbone of cybersecurity operations. During this week, I learned how operating systems communicate, how networks are structured, and how to navigate a Linux environment using the command line.

These skills are essential for Security Operations Center (SOC) analysts, incident responders, penetration testers, and cloud security professionals.
