# Day 19 – Wireless Network Security

## Objective

Understand how wireless networks work, common wireless security standards, wireless attacks, and best practices for securing Wi-Fi networks.

---

# What is a Wireless Network?

A wireless network allows devices to communicate without physical cables by using radio waves.

Examples:
- Home Wi-Fi
- Office Wi-Fi
- School networks
- Public hotspots

Advantages:
- Mobility
- Easy installation
- Flexible access

Disadvantages:
- More vulnerable to attacks than wired networks.
- Signals can travel beyond the building.

---

# Wireless Access Point (WAP)

A Wireless Access Point (WAP) is a networking device that allows wireless devices to connect to a wired network.

Functions:
- Broadcasts the Wi-Fi signal.
- Connects wireless devices.
- Manages wireless communication.

---

# Service Set Identifier (SSID)

The SSID is the name of a wireless network.

Example:

HomeWiFi

Office_Network

The SSID helps users identify the correct wireless network.

---

# Wireless Encryption Standards

## WEP (Wired Equivalent Privacy)

The first Wi-Fi security standard.

Characteristics:
- Weak encryption
- Easily cracked
- No longer recommended

---

## WPA (Wi-Fi Protected Access)

Improved security over WEP.

Characteristics:
- Better encryption
- More secure than WEP
- Still outdated today

---

## WPA2

Currently one of the most widely used wireless security standards.

Uses AES encryption.

Benefits:
- Strong security
- Trusted by organizations
- Recommended for most networks

---

## WPA3

The newest wireless security standard.

Improvements:
- Stronger encryption
- Better password protection
- Improved resistance against brute-force attacks

Best choice for modern wireless networks.

---

# Wireless Authentication

Authentication verifies that a user is allowed to access the wireless network.

Common methods:

- Pre-Shared Key (PSK)
- Enterprise Authentication (802.1X)

Enterprise authentication is commonly used in organizations because each user has unique credentials.

---

# Common Wireless Attacks

## Evil Twin Attack

An attacker creates a fake Wi-Fi network with the same SSID as a legitimate one.

Users unknowingly connect to the fake network.

Goal:
- Steal credentials
- Monitor traffic

Protection:
- Verify network names.
- Use VPNs.
- Avoid unknown Wi-Fi.

---

## Rogue Access Point

An unauthorized wireless access point installed on a network.

Risks:
- Bypass security controls.
- Allow unauthorized access.

Protection:
- Regular wireless scans.
- Network monitoring.

---

## Deauthentication Attack

An attacker sends fake deauthentication frames to disconnect users from Wi-Fi.

Purpose:
- Force reconnection.
- Capture authentication handshakes.

Protection:
- WPA3
- Protected Management Frames (PMF)

---

## War Driving

War Driving involves driving around searching for vulnerable wireless networks.

Attackers use laptops or smartphones to locate:
- Open Wi-Fi
- Weakly secured networks

Protection:
- Strong encryption.
- Disable unnecessary SSID broadcasting if appropriate.
- Monitor for unauthorized access.

---

# Best Practices for Wireless Security

- Use WPA3 whenever possible.
- If WPA3 is unavailable, use WPA2.
- Never use WEP.
- Create strong Wi-Fi passwords.
- Change default router credentials.
- Update router firmware regularly.
- Disable WPS.
- Monitor connected devices.
- Use a guest network for visitors.

---

# Why Wireless Security Matters

Many organizations rely heavily on wireless connectivity.

Poorly secured Wi-Fi can allow attackers to:
- Access sensitive information.
- Steal credentials.
- Launch attacks against internal systems.

Strong wireless security reduces these risks.

---

# Key Takeaways

- Wireless networks use radio waves instead of cables.
- WEP is outdated and insecure.
- WPA2 is widely used.
- WPA3 offers the strongest protection.
- Evil Twin attacks create fake Wi-Fi networks.
- Rogue Access Points provide unauthorized wireless access.
- Deauthentication attacks disconnect users.
- Strong passwords and modern encryption improve wireless security.
