# 📖 Overview

This week focused on Identity and Access Management (IAM), one of the most critical domains in cybersecurity. I learned how organizations verify user identities, control access to resources, and enforce security policies to protect sensitive information.

Identity and Access Management is fundamental to preventing unauthorized access and is widely used across enterprise environments, cloud platforms, and Security Operations Centers (SOCs).

This week reinforced the importance of identity as the first layer of cybersecurity.
